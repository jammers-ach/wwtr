# Box


## Generation

* Go to https://www.templatemaker.nl/en/
* Select Box with lid
* Enter dimentions
* Download the PDF
* Use inkscape to take the outlines of the box into two SVG files
* Save that layer as `outline`
* Add a new layer `text`
* Copy the contents of `templates/{front,back,sides}.svg` onto your box template (rearranging as nessecary)

## Assembly

Either:
* Print the whole file onto cardboard of the right thickness, score, fold and glue

Or:
* print the `outline` layer onto your cardboard, score fold and glue
* print out the `text` layer onto paper, cut out, cut off the tabs, glue that ontop of the folded box
